# V152 Motion refinement
Builds on V151; preserves existing data, map geometry, controls and design. Structural and viewport-bound reveals now cover activities, rail, budget statistics, group voting, photo collections and day planning. The existing IntersectionObserver cap of 42 cards and 12 structural targets remains; no permanent animation loop or animation on the map canvas. Galleries fade in on actual image load, photo viewer resets the load class on navigation, hover zoom only on fine pointers, touch feedback on explicit controls, budget bars animate without altering amounts. New CSS uses opacity/transform, honors prefers-reduced-motion and the local motion setting. No added dependency. Unit and browser assertions added; new CI must be checked before claiming success.
